# Physics-Informed Neural Operator with Conformal Certification for Transient Stability Assessment

Reproduction code for the paper **"A Physics-Informed Neural Operator with Conformal
Certification for Fast Transient Stability Assessment"**.

A physics-informed neural operator (DeepONet with a Fourier-feature trunk) maps a fault scenario
to the full center-of-inertia (COI) rotor-angle trajectory, with a split-conformal certified error
bound. The key enabler is the **physics-informed input encoding**: the initial-acceleration vector
$a_i(k)=(P_{mi}-P_{ei}^{\mathrm{f}}(k))/M_i$ computed from the swing equation, which lets the
operator generalize to fault locations and $N{-}1$/$N{-}2$ topologies unseen during training.

## Requirements

- Python >= 3.9
- PyTorch >= 2.0 (a CUDA GPU is recommended but not required)
- numpy, pandas, pandapower (IEEE 39-bus / 118-bus test systems)
- matplotlib (only for the conformal-analysis figure)

```bash
pip install numpy pandas pandapower torch matplotlib
```

## Quick start (main results, IEEE 39-bus, Table 1)

```bash
# 1. Generate the dataset: 2160 train / 540 val / 960 test scenarios
#    (12 test fault buses held out entirely from training; ~5 min on CPU)
python generate_data.py

# 2. Train the operator (p=512, 600 epochs; ~5 min on an RTX 4070)
python train.py --p 512 --epochs 600 --tag p512

# 3. Evaluate: pooled RMSE, fault-on/post-fault split, classification,
#    CCT, split-conformal interval, speedup
python evaluate.py --model model_p512.pt --p 512
```

Expected (Table 1): fault-on RMSE 2.3°, post-fault RMSE 36.8°, classification accuracy 96.7%,
CCT error 12.3 ms, conformal q̂=111° with coverage 0.893 at α=0.1.

The like-for-like speedup (Sec. 5.3) is measured separately:

```bash
python measure_speedup.py   # ~700x CPU operator vs CPU RK4; ~1300x on GPU
```

## Implementation notes

- **Severity encoding** (Sec. 4.1): the fault-on vector `(Pm - Pe^f)/M` and the post-fault vector
  `(Pm - Pe^post)/M` are computed per fault bus / tripped line by Kron-reducing the fault-on /
  post-fault network (`power_system.py`, `fault_pe` / `post_yint`).
- **Physics-residual loss** (Sec. 4.3): the COI-frame residual includes the synchronous speed
  ωs explicitly (`model.py:physics_residual`); an early implementation omitted it, which
  inflated the earlier ablation numbers (Sec. 6.7).
- **Conformal certification** (Sec. 4.4, 6.6): split conformal prediction — the 355 stable test
  scenarios are split into disjoint calibration (177) and evaluation (178) halves.
- The classical simulator (undamped swing equations, RK4 at 0.5 ms) is implemented from scratch
  in `power_system.py` / `dataset.py`; only the static IEEE 39/118-bus data come from pandapower.
