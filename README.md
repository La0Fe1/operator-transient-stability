# Physics-Encoded Neural Operator with Conformal Trajectory Bands for Transient Stability Assessment

Reproduction code for the paper **"A Physics-Encoded Neural Operator with Conformal Trajectory
Bands for Fast Transient Stability Screening"** (revision 2026-09-16; the paper and this
repository were corrected jointly after a pre-submission code audit).

A physics-encoded neural operator (DeepONet with a Fourier-feature trunk) maps a fault scenario
to the full center-of-inertia (COI) rotor-angle trajectory, with a split-conformal calibrated
trajectory band (a coverage-valid band, not a stability certificate). The key enabler is the **physics-informed input encoding**: the initial-acceleration vector
$a_i(k)=(P_{mi}-P_{ei}^{\mathrm{f}}(k))/M_i$ computed from the swing equation, which lets the
operator generalize to fault locations and $N{-}1$/$N{-}2$ topologies unseen during training.

## Requirements

Environment used for the reported results: Python 3.12, PyTorch 2.13.0 (+cu126), NumPy 2.4.4,
pandas 2.3.3, pandapower 3.5.4, matplotlib 3.11.1 (see `requirements.txt`). A CUDA GPU is
recommended but not required for evaluation.

```bash
pip install -r requirements.txt
```

## Quick start (main results, IEEE 39-bus, Table 2)

```bash
# 1. Generate the dataset: 2160 train / 540 val / 960 test scenarios
#    (12 test fault buses held out entirely from training; ~5 min on CPU)
python generate_data.py

# 2. Train the operator (p=512, 600 epochs; ~5 min on an RTX 4070)
python train.py --p 512 --epochs 600 --tag p512

# 3. Evaluate: pooled RMSE, fault-on/post-fault split, classification,
#    CCT, split-conformal interval, speedup
python evaluate.py --model model_p512.pt --p 512
```

Expected (Table 2, seed 0, max-over-time criterion): fault-on pooled RMSE 2.3°,
post-fault pooled RMSE 36.9°, full-horizon pooled RMSE 36.3°, classification accuracy 95.4%
(TP/FP/FN/TN = 318/6/38/598), CCT error 25.2 ms mean |err|, per-machine band q̂=110.1° with
coverage 0.882 (157/178) and pairwise bound 148° at α=0.1. All paper numbers are exported by
`recompute_all.py` (plus `recompute_extras.py`, `recompute_cct2.py`, `variants_acc.py`,
`decidable_vs_alpha.py`, `n12_rmse.py`), which apply the audit-corrected protocols:
A1 signed pairwise score, A2 max-over-time stability criterion, A3 gated coverage on the
disjoint evaluation half, A4 order-statistic quantile, B6 event-aligned RK4 reference
(`dataset.py:simulate_batch` splits each step at the clearing instant).

The like-for-like speedup (Sec. 5.3) is measured separately:

```bash
python measure_speedup.py   # throughput 214x CPU vs CPU RK4; end-to-end CCT search 318x
```

## Implementation notes

- **Severity encoding** (Sec. 4.1): the fault-on vector `(Pm - Pe^f)/M` and the post-fault vector
  `(Pm - Pe^post)/M` are computed per fault bus / tripped line by Kron-reducing the fault-on /
  post-fault network (`power_system.py`, `fault_pe` / `post_yint`).
- **Physics-residual loss** (Sec. 4.3): the COI-frame residual includes the synchronous speed
  ωs explicitly (`model.py:physics_residual`); an early implementation omitted it, which
  inflated the earlier ablation numbers (Sec. 6.7).
- **Conformal calibration** (Sec. 4.4, 6.6): split conformal prediction with the
  order-statistic quantile k=ceil((n_cal+1)(1-α)) — the 356 stable test scenarios are split into
  disjoint calibration (178) and evaluation (178) halves; the pairwise score uses signed errors.
- The classical simulator (undamped swing equations, event-aligned RK4 at 0.5 ms) is
  implemented from scratch in `power_system.py` / `dataset.py`; only the static IEEE
  39/118-bus data come from pandapower. The 118-bus experiment is a **synthetic dynamic case**:
  Demetriou-table parameters assigned to case118 generators by rated capacity, without the
  per-machine bus mapping or per-unit base conversion of the original benchmark (audit A6).
